# Releases / Sürümler

## English

Hamartia publishes one GitHub Release after each merged PR once the desktop release workflow is active. Release tags use a sequential themed code (`ARETE-001`, `ARETE-002`, ...). Each release includes bilingual notes and the Windows installer, Debian package, and AppImage.

The workflow appends each published bilingual note to this file. Pull requests merged before the workflow is introduced cannot trigger a release retroactively.

See the [GitHub Releases page](https://github.com/Nec0ti/hamartia/releases) for current downloads and notes.

## Türkçe

Masaüstü sürüm iş akışı etkinleştikten sonra birleştirilen her PR için bir GitHub Release yayımlanır. Sürüm etiketleri sıralı ve temalı kod kullanır (`ARETE-001`, `ARETE-002`, ...). Her sürümde iki dilde notlar, Windows kurulum programı, Debian paketi ve AppImage bulunur.

İş akışı yayımladığı her iki dilli notu bu dosyaya ekler. İş akışı eklenmeden önce birleştirilmiş PR'lar geriye dönük olarak release tetikleyemez.

Güncel indirme dosyaları ve notlar için [GitHub Releases sayfasına](https://github.com/Nec0ti/hamartia/releases) bak.
