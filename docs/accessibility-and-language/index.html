Accessibility and language

Language preference and verified accessibility guidance.

Hamartia currently offers English (default) and Turkish. Change the app language in Settings. Number/date formatting follows the selected locale for supported UI flows.

Switch language

Choose English or Türkçe from the Settings language selector. The app stores this preference in the current browser profile. Reloading the app should retain it. The documentation language switch opens the matching page when a translation exists.

Using the interface

Use semantic buttons and form labels; keyboard users can move between controls with Tab and activate buttons with Enter/Space. Timer state is exposed as text and due reminders remain visible rather than depending only on a notification. Browser/system screen-reader and contrast behavior can vary by OS and version. The repository's smoke checks cover selected labels, focus, and viewport behavior; they are not a complete screen-reader certification.

Report a barrier

If a label, focus order, keyboard action, contrast, or translation blocks a task, include the page/screen, OS and app version, language, and expected/actual behavior in a GitHub issue. Do not attach real study records, account tokens, or API keys. See Contributing.
