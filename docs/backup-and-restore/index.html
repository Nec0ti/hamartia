Backup and restore

Create a portable ZIP and safely restore it on this or another computer.

Backups are manual ZIP files. Store them somewhere you control and protect them as private study records. Hamartia does not sync them automatically.

Create a backup

  1. Open Settings and select Download backup.
  2. Save the ZIP to a location you can find. Move it to another computer using a transfer method you trust.
  3. The archive includes study records, learning-evidence reflections, optional local onboarding and student-profile data, question images, settings except secret key material, and Clock state. The configured endpoint API key and ChatGPT sign-in credentials are not included.

Restore in the desktop app

  1. Open Settings and choose Restore backup, then select the ZIP.
  2. Read the confirmation. Restore replaces current study data; Hamartia first saves a timestamped snapshot of the existing data folder.
  3. Confirm and keep the app open while it validates, restores, restarts, and reloads.

Clock timers restore paused with their remaining/elapsed time frozen at backup creation; imported reminders restore disabled. Review them and explicitly resume or enable them.

Older backups and errors

Current restore validates archive paths, sizes, checksums, data schemas, and referenced uploads before replacing data. Older supported archives without newer optional records receive safe defaults. A failed validation should leave current data in place. Keep the original ZIP until you have checked the restored records. See Troubleshooting.

Restore is replacement. It does not merge two histories. Make a fresh backup of the destination computer first if you may need its current data.
