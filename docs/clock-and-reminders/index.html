English / Clock and reminders

Clock and reminders

Use the local clock, one shared timer, and optional due notifications.

Clock shows local date/time and offers Pomodoro, countdown, stopwatch/laps, and one-off or weekday reminders. Study Plan focused practice and Clock use one shared active timer; a second active timer cannot run in parallel.

Pomodoro, countdown, and stopwatch

Set Pomodoro work/break durations, then start, pause, resume, reset, or skip a phase. The default interval is a convenience, not a claim of an optimal study schedule. Countdown accepts a duration. Stopwatch records elapsed time and laps. The display is derived from saved timestamps rather than counting UI ticks.

Focused practice

Starting focused practice from a Study Plan topic uses the shared timer. Correct, incorrect, and blank counters belong to that practice draft. Finish saves one completed practice set; cancelling discards the draft after confirmation. If a Clock timer is already active, resolve it before starting another.

One-off and recurring reminders

Reminders use the device's local time zone. Recurrences can select weekdays. Choose whether to allow Web Notifications; keep reminders enabled only if you want alerts. Due events are reconciled while the app is running, including when another Hamartia tab is selected. Overdue reminders remain visible in Clock. After missed recurring occurrences, the app advances to the next future time rather than replaying a burst.

Delivery limits

Notifications are checked only while the app is open and the device is awake. Hamartia cannot wake the device and does not promise delivery after the app closes. OS notification settings can suppress alerts. Daylight-saving gaps/folds follow the documented local JavaScript date behavior; other regions depend on the device time-zone database.

Restart and backup

Timer state is saved locally and restored after app restart. ZIP backup freezes timers at export time; restore pauses those timers and disables imported alarms. Review them before use. See Backup and restore.
