Contributing

Improve Hamartia or adapt its exam workflow for another format.

Hamartia is MIT-licensed. Contributions can improve a shared workflow or adapt a different exam structure, provided scoring and data behavior are explicit.

Before changing code

Read the repository AGENTS.md, notes.md, backlog, and latest reports. Preserve existing user records and old backups. Keep local-model execution and quality out of CI tests/benchmarks; use mocks for provider error paths.

Adapting exam formats

Describe exam/session types, section relationships, scoring formula, validation boundaries, trends, and compatibility with old records/backups. Keep curriculum references separate from scoring. Include an explicit correctness oracle for score calculations and update English/Turkish UI and docs together.

Documentation changes

Update both language versions with the same page IDs, links, factual scope, and cross-links. Run python3 scripts/build_docs.py, the frontend docs browser smoke, and link/accessibility checks. Describe only behavior in the shipped app; record manual OS/account gates separately from automated evidence.

Submit a report

Include a concise problem statement, user-visible change, tests and commands, limits, and report path. Use fictional data in screenshots. Never include personal student records, API keys, or ChatGPT credentials.
