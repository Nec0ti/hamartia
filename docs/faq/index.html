FAQ

Short answers to common setup, data, scoring, and study questions.

These answers summarize common product boundaries. Use the linked guides for the exact workflows and steps.

Does Hamartia need AI?

No. The main exam, mistake, practice, review, and Clock flows are local. Study Agent and question analysis are optional.

Does it sync my records?

No automatic cross-device sync. Create and move a backup yourself. Credentials are not carried in the backup.

What is the optional student profile?

It is an editable, local profile for age in years, free-form grade/curriculum, study preferences, goals, and a built-in avatar. It is optional and separate from exam results. You can edit or clear it in Settings; it is included in backups, but excluded from Study Agent and question-analysis requests. See Privacy and consent and Backup and restore.

Can I record other exam formats?

It records TYT/AYT full mocks, user-defined custom mocks, and single-subject exams, with the legacy YKS profile available by default. A custom mock lets you name the format, add 1–12 sections with your own labels, and select any existing versioned scoring profile. You can define and version a custom exact-rational scoring rule for other formats, but labels and rules are user-entered and do not certify official alignment. See Exam formats.

What happens to results if I edit a scoring profile?

Saved exams and practice sets keep an immutable snapshot of the selected rule. Editing a profile creates a new version for future records; old results and trends remain tied to their original profile version. See Study workflows.

Is the configured endpoint guaranteed local?

No. The URL can name a remote host; Hamartia does not verify locality or network isolation. See Study Agent.

Will a reminder wake my computer?

No. Delivery is not guaranteed while the app is closed or the computer sleeps. See Clock and reminders.

Does a better streak or XP prove that I learned more?

No. These are app progression records. They are not an independent learning assessment. See Learning evidence.
