Getting Started

Install Hamartia, choose a language, and make a first study record.

Hamartia keeps exam history, missed questions, focused practice, and review records on this computer. Start with the desktop app; an AI provider is optional.

1. Download and install

Use the latest GitHub release. Choose the Windows installer for Windows 10/11, the .deb for Debian-based Linux, or the AppImage for compatible Linux desktops. Detailed steps are on Install by operating system.

2. Choose a language

On first launch, choose English or Türkçe. English is selected by default. A short walkthrough explains the main screens, then an optional survey asks about grade/year, curriculum, study preferences, and goals. You can skip either step, change the language in Settings, replay the walkthrough, or edit and clear your profile later. The documentation also has a Turkish version using the language link at the top of every page.

3. Record your first session

  1. On Dashboard, add a TYT/AYT full mock or a single-subject exam and enter its date, duration, and results.
  2. Open My Mistakes to save a missed question as text or attach a supported image. Add subject and topic labels; if it came from an exam, capture it there to keep the exam context.
  3. Open Study Plan to see due questions, topic priorities, and focused practice. Its stopwatch uses the same timer shown in Clock.

Where your data lives

Hamartia stores its records in this OS user's application-data folder. Data is not synced between computers automatically. Create a ZIP backup in Settings before moving records. See Backup and restore and Privacy and consent.

AI is optional. Exam entry, review scheduling, topic summaries, practice records, and Clock work without an AI provider. Study Agent and question analysis are separate optional features with distinct data flows.
