GETTING STARTED

Run the development build.

Desktop installers for Windows and Linux are planned. For now, Hamartia runs from its source checkout.

1

Install prerequisites

Use Python 3.12 and Node.js 22. From the repository root, install the Python and frontend dependencies:

python3.12 -m venv .venv
.venv/bin/python -m pip install -r backend/requirements.txt
cd frontend && npm ci
2

Start Hamartia

From the repository root, run the launcher. Open the local address it prints in your browser. The interface starts in English; change it to Turkish or English in Settings. Your choice is saved on this computer.

.venv/bin/python scripts/dev.py

Press Ctrl + C to stop both servers. By default, the app uses ports 5173 and 8000 on this computer.

3

Keep your data safe

Exams, questions, images, and settings live in backend/data/. Use Settings to download a ZIP backup before moving or restoring your records.

YOUR DATA

Local by default. Clear when AI is involved.

The development app stores study records and uploaded images under backend/data/ on this computer. It has no account sync or ChatGPT sign-in yet.

Optional question analysis can send the question text and image to the OpenAI-compatible endpoint configured in Settings. Only connect to an endpoint you trust. The API key is omitted from API responses and backups, but is stored in the local settings file; it is not encrypted by the current development app.

The local API is intended for use on this computer. Do not expose it to the public internet.

BACKUP & RESTORE

A backup you can take with you.

Download a ZIP backup from Settings. The archive contains your study records and question images, but not the saved API key.

Close Hamartia before restoring. From the repository root, run:

.venv/bin/python scripts/restore_backup.py hamartia-backup.zip

Restore validates the archive and keeps the current data directory as a timestamped backup before replacing it. On Windows, use .venv\Scripts\python.exe.
