EDUCATIONAL DIRECTION

Learning patterns, with room for the learning process.

Hamartia grew from Turkish mock-exam workflows, but a mock-exam score is only one kind of learning evidence. Türkiye's Maarif Model describes teaching programs through learning outcomes and a broader assessment approach that includes ongoing feedback and varied evidence; MEB phases the curriculum rollout by grade. The Study Agent remains a general assistant, not an official or verified Maarif alignment system. You can attach a generic user-entered curriculum reference to a missed question: framework, source/version, grade/year, unit/theme, a short outcome note or paraphrase, process component, and optional source URL. The existing subject field supplies course/subject. Hamartia does not import MEB curriculum text. It does not automatically fetch or verify the source URL; you can open it yourself. With a reference, the Study Agent can cautiously relate supported mistake patterns to your note and propose a next activity plus a separate evidence task with observable criteria. It does not infer mastery from one answer or record task completion.

The Maarif Model is a curriculum framework, not a replacement name for national exams: the 2026 YKS schedule lists TYT, AYT, and YDT, and MEB published a separate 2026 central-exam guide for secondary-school placement. Read MEB's Maarif assessment overview, common text, and current curriculum rollout plans. Hamartia's current built-in exam and scoring support is described below; different curriculum structures may need adaptation.

GETTING STARTED

Install the desktop app.

Download the latest release for Windows 10/11 or Linux x64 from GitHub Releases.

Hamartia grew from Turkish LGS and YKS mock-exam workflows. This version has TYT/AYT full mocks and single-subject exams, with free-text subject and topic labels. Its built-in net calculation uses the YKS wrong-answer penalty; mock-exam workflows with compatible scoring can reuse it, while different exam structures or scoring rules may need adaptation through a contribution or fork. The interface currently supports English and Turkish. Contributions and forks are welcome under the MIT license.

1

Choose a package

Windows 10/11: download and run the Windows installer (.exe). Debian: install the .deb package with your package installer or run:

sudo apt install ./Hamartia-*.deb

Linux AppImage: make the downloaded file executable, then open it:

chmod +x Hamartia-*.AppImage
./Hamartia-*.AppImage
2

Choose your language

Hamartia starts in English. In Settings, select English or Turkish; your preference is saved on this computer.

3

Find your data

Exams, questions, images, settings, and practice history are stored in Hamartia's per-user application data folder. They remain on this computer unless you create and move a backup.

YOUR DATA

Local by default. Clear when AI is involved.

Hamartia stores study records and uploaded images in a per-user application data folder on this computer. ChatGPT sign-in is available in the packaged desktop app. The packaged desktop app defaults to the ChatGPT subscription for its Study Agent; OpenAI asks separately for permission to use the user's ChatGPT plan. An optional OpenAI-compatible endpoint can be selected explicitly in the Study Agent. Eligible ChatGPT accounts and usage limits vary.

Before each request, Hamartia asks for consent to send the typed question and a bounded summary: pending/scheduled counts, up to eight subject/topic/tag summaries, up to eight topic-practice aggregates (set count, net, accuracy), and up to eight user-entered curriculum references from active mistakes. A reference may include course/subject, framework, source/version, grade/year, unit/theme, your short outcome note/paraphrase, process component, and optional source URL. References are unverified; Hamartia does not import curriculum text. Hamartia does not automatically fetch or verify the source URL; you can open it yourself. Saved question-record text/images and chat history are excluded; Hamartia does not save Study Agent transcripts. ChatGPT requests go directly to OpenAI's public Responses API with storage disabled. Configured-endpoint consent names the exact URL and the same payload categories, explains that the endpoint may be remote, and says if a saved API key is sent for authentication. The endpoint operator may have its own retention rules. Hamartia never silently changes providers.

ChatGPT tokens are kept in OS-protected local storage. If that protection is unavailable, sign-in is disabled. Sign out attempts to revoke the renewable session; if OpenAI cannot confirm, Hamartia clears its local tokens and tells you to disconnect the app in ChatGPT settings. If an encrypted connection file becomes unreadable, you can explicitly confirm removing that local file; Hamartia keeps its host ID, but cannot inspect or revoke the unreadable remote session, so disconnect it in ChatGPT settings. The saved account link can be removed locally to use another ChatGPT account.

Optional question analysis and the optional configured Study Agent can send data to the OpenAI-compatible endpoint in Settings. Other hosts are allowed; Hamartia does not verify that the service is local or network-isolated. Review the exact destination and use only an endpoint you trust. The API key is omitted from API responses and backups, but the current app stores it unencrypted in its local settings data. The local API is bound to this computer; do not expose it to the public internet.

OPTIONAL MANUAL CHECKS

Try the AI features with fictional study data.

These checks are for your own trusted services and packaged desktop app. Never put API keys, account tokens, or real study details in screenshots or reports.

P3 · CONFIGURED ENDPOINT

Check your OpenAI-compatible service.

  1. Create a disposable text-only missed question with a fictional curriculum reference (for example, an invented framework and outcome; no MEB text). In Settings, enter the endpoint URL, model name, and API key if your service requires one. Save them without sharing or photographing the key.
  2. Open Study Agent, choose Configured OpenAI-compatible endpoint (optional), and confirm the displayed URL and model. Read any remote-host or unencrypted-HTTP warning. The endpoint may be remote, and its operator may retain requests; use only a service you trust.
  3. Enter a harmless fictional prompt such as: “Suggest one short activity for an imaginary learner reviewing topic T-01.” Review the per-request consent, including the exact destination, curriculum-reference categories, and whether the saved key will be sent, then send.
  4. Confirm that you receive a useful response or a clear endpoint error. Hamartia does not switch to ChatGPT when this provider fails; check the URL, model, and service configuration if it errors.
  5. Optional: separately use Review with Local AI with a disposable question that has invented text. Question analysis can send that text or image to the configured endpoint. Try a synthetic image only if you want to verify multimodal support, then remove the disposable record.

P5 · CHATGPT DESKTOP

Check ChatGPT sign-in and sign-out.

  1. In the packaged desktop app, choose ChatGPT subscription (default), continue with ChatGPT, sign in, and separately approve OpenAI’s request to use your ChatGPT plan.
  2. Choose a model shown as available to your account. Enter a harmless fictional prompt for the disposable question and review the per-request consent, including any user-entered reference data, before sending.
  3. Confirm that a response appears. If it fails, read the displayed error; the app will not switch to the configured endpoint.
  4. Choose Sign out and check whether OpenAI confirms remote revocation. If the app says revocation was not confirmed, follow its notice to disconnect Hamartia in ChatGPT settings.

BACKUP & RESTORE

A backup you can take with you.

In Settings, choose Download backup to save a ZIP containing your study records and question images. The ZIP does not contain the local API key.

To restore, choose Restore backup in Settings, select the ZIP, and confirm. Hamartia validates the archive, keeps a timestamped snapshot of your current data, preserves the API key already on this computer, and then restarts.

Restore the backup only in Hamartia; keep the app open until it reports the result.
