Install by operating system

Choose the packaged desktop installer for Windows or Linux.

Hamartia publishes a Windows installer, Debian package, and Linux AppImage. Download the current files from GitHub Releases. Packages are for x64; no macOS package is currently documented.

Windows 10/11

  1. Download the Windows .exe installer.
  2. Run it and follow the installer prompts. Choose the install folder if desired.
  3. Launch Hamartia from the installed shortcut. User data is kept separately in the current Windows user's application-data directory.

If Windows blocks or warns about the installer, verify the file came from the project’s Releases page before deciding whether to continue. Do not download a similarly named binary elsewhere.

Debian and compatible distributions

Download the release .deb file. Open it with the system package installer, or from the directory containing the file run:

sudo apt install ./Hamartia-linux-x64.deb

Use the actual downloaded filename if it differs. The package manager may ask to install dependencies.

Linux AppImage

Download the AppImage and run these commands from its directory:

chmod +x Hamartia-linux-x64.AppImage
./Hamartia-linux-x64.AppImage

Use the actual filename. Some desktops require FUSE or system integration support; consult your distribution if it does not start.

First launch

The app starts in English. Change language in Settings. Study data is stored separately from the installer files in the OS user's application-data area. Before uninstalling or moving computers, make a backup rather than assuming that reinstalling will recover it. See Backup and restore and Troubleshooting.
