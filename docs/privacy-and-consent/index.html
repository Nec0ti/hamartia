Privacy and consent

Where records are stored and what optional AI requests send.

By default, study records are stored in the current OS user's application-data folder. There is no automatic cloud sync. Moving or sharing a backup is a separate action.

Local records

Exam results, saved missed questions and images, review attempts, topic-practice records, Clock timers and reminders, progression data, and settings are stored locally. The Clock notification preference and reminders are local state; due alerts are checked only while Hamartia is running and the device is awake. Notifications can be suppressed by OS settings.

Study Agent requests

Each request requires explicit consent and goes directly to the selected provider. ChatGPT calls use OpenAI's public Responses API with storage disabled by the app. The prompt and bounded summary categories are shown before sending. In Practice Session entry, the current conversation is sent without saved study records or the general summary. ChatGPT receives a strict quote-only evidence function; the configured endpoint receives the equivalent evidence-only tool. Hamartia checks quote hints against the host-owned transcript, shows a verified preview, and writes only after explicit approval. The provider cannot write records. Hamartia does not store Study Agent transcripts. Configured endpoints may be remote and may have their own retention rules.

Question analysis

Question analysis is a separate user-triggered request. It can send the selected question's text/image to the configured OpenAI-compatible endpoint. Do not assume it has the same payload as Study Agent. Review Settings and the exact endpoint before use.

Credentials

ChatGPT renewable credentials use OS-protected storage; sign-in is unavailable if that protection cannot be used. The configured endpoint API key is stored unencrypted in local settings, not returned by the Settings API and not included in backups. Do not publish logs, screenshots, or backups containing private study material or credentials. See Study Agent and providers and Backup and restore.
