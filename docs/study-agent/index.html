Study Agent and providers

Select the desktop Study Agent provider and understand its controls.

The Study Agent is optional and available in the packaged desktop app. Question analysis is a separate optional action in My Mistakes. Neither is needed for ordinary exam, review, practice, or Clock flows.

ChatGPT subscription

The desktop Study Agent defaults to ChatGPT subscription. Select sign-in, complete the ChatGPT flow, and separately approve OpenAI's request to use the ChatGPT plan. Available models and usage limits depend on the account. Hamartia does not silently switch providers if a request fails. Sign out attempts remote revocation; follow the app's instructions if OpenAI cannot confirm it.

Configured OpenAI-compatible endpoint

In Settings, enter the endpoint URL, model name, and optional API key. Select the configured endpoint explicitly in Study Agent. It may run on this computer or on a remote host: Hamartia does not verify that it is a local model or isolated from the network. Review the exact URL, transport warnings, and per-request consent. The operator may retain requests under its own policy. The API key is stored unencrypted in local app settings and is omitted from backups and API responses.

Consent and request content

Before each Study Agent request, Hamartia displays a consent screen. It sends the typed prompt plus a bounded summary of saved study counts, subject/topic/tag summaries, topic-practice aggregates, and up to eight user-entered curriculum references. Saved question text and images and Study Agent conversation history are not included or stored by Hamartia. The consent screen describes the destination and data categories. Read it before sending and decline if you do not want the request sent.

Question analysis

“Review with Local AI” uses the configured OpenAI-compatible endpoint and may send that saved question's text or image. The endpoint can be remote; “local” in the control label is not a locality guarantee. The actual model behavior and local machine setup have not been verified by this documentation. See Privacy and consent.
