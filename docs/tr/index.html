ÇALIŞMA ALANI

İşe yarayan ayrıntılar elinin altında.

01

Deneme geçmişi

TYT, AYT ve branş denemelerini kaydet. Tam TYT/AYT oturumlarında ders sonuçları birlikte tutulur ve ders bazlı eğilimler korunur.

02

Yanlış sorular

Soruyu metin veya görsel olarak kaydet, ders ve konu etiketleri ekle, zamanla tekrar gözden geçir.

03

Çalışma ilerlemesi

Cevap geçmişini, odaklı çalışma oturumlarını, konu eğilimlerini ve kayıtlarından çıkarılan öncelikleri izle.

BAŞLANGIÇ

Geliştirme sürümünü çalıştır.

Windows ve Linux kurulum paketleri planlanıyor. Şimdilik Hamartia kaynak kodundan çalışıyor.

1

Gerekli araçları kur

Python 3.12 ve Node.js 22 kullan. Depo kök dizininde Python ve arayüz bağımlılıklarını yükle:

python3.12 -m venv .venv
.venv/bin/python -m pip install -r backend/requirements.txt
cd frontend && npm ci
2

Hamartia'yı başlat

Depo kök dizininden başlatıcıyı çalıştır. Tarayıcıda yerel adresi aç. Arayüz İngilizce açılır; Ayarlar'dan İngilizce veya Türkçe seçebilirsin. Tercihin bu bilgisayarda saklanır.

.venv/bin/python scripts/dev.py

İki sunucuyu da durdurmak için Ctrl + C tuşlarına bas. Varsayılan olarak uygulama bu bilgisayarda 5173 ve 8000 portlarını kullanır.

3

Verilerini koru

Denemeler, sorular, görseller ve ayarlar backend/data/ altında tutulur. Kayıtlarını taşımadan veya geri yüklemeden önce Ayarlar'dan ZIP yedeği indir.

VERİLERİN

Varsayılan olarak yerel. AI kullanırken açıkça belirtir.

Geliştirme sürümü çalışma kayıtlarını ve yüklenen görselleri bu bilgisayardaki backend/data/ klasöründe tutar. Henüz hesap eşitleme veya ChatGPT ile giriş özelliği yoktur.

İsteğe bağlı soru analizi, soru metnini ve görselini Ayarlar'da yapılandırdığın OpenAI uyumlu uç noktaya gönderebilir. Yalnızca güvendiğin bir uç noktaya bağlan. API anahtarı API yanıtlarına ve yedeklere eklenmez; yerel ayar dosyasında saklanır ve mevcut geliştirme sürümünde şifrelenmez.

Yerel API bu bilgisayarda kullanım içindir. İnternete açık hale getirme.

YEDEKLEME VE GERİ YÜKLEME

Yanında götürebileceğin bir yedek.

Ayarlar'dan ZIP yedeği indir. Arşiv çalışma kayıtlarını ve soru görsellerini içerir; kayıtlı API anahtarını içermez.

Geri yüklemeden önce Hamartia'yı kapat. Depo kök dizininde şu komutu çalıştır:

.venv/bin/python scripts/restore_backup.py hamartia-backup.zip

Geri yükleme arşivi doğrular ve değiştirmeden önce mevcut veri klasörünü tarihli bir yedek olarak saklar. Windows'ta .venv\Scripts\python.exe yolunu kullan.
