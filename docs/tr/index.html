YEREL ÖNCELİKLİYKS ÇALIŞMA ALANIAÇIK KAYNAK

ÇALIŞMA ALANI

İşe yarayan ayrıntılar elinin altında.

01

Deneme geçmişi

TYT, AYT ve branş denemelerini kaydet. Tam TYT/AYT oturumlarında ders sonuçları birlikte tutulur ve ders bazlı eğilimler korunur.

02

Yanlış sorular

Soruyu metin veya görsel olarak kaydet, ders ve konu etiketleri ekle, zamanla tekrar gözden geçir.

03

Çalışma ilerlemesi

Cevap geçmişini, odaklı çalışma oturumlarını, konu eğilimlerini ve kayıtlarından çıkarılan öncelikleri izle.

BAŞLANGIÇ

Masaüstü uygulamasını yükle.

Windows 10/11 veya Linux x64 için en son sürümü GitHub Releases sayfasından indir.

1

Paketi seç

Windows 10/11: Windows yükleyicisini (.exe) indirip çalıştır. Debian: .deb paketini yazılım yükleyicisiyle yükle veya şu komutu çalıştır:

sudo apt install ./Hamartia-*.deb

Linux AppImage: İndirdiğin dosyayı çalıştırılabilir yap ve aç:

chmod +x Hamartia-*.AppImage
./Hamartia-*.AppImage
2

Dilini seç

Hamartia İngilizce açılır. Ayarlar'dan İngilizce veya Türkçe seç; tercihin bu bilgisayarda saklanır.

3

Verilerinin konumu

Denemeler, sorular, görseller, ayarlar ve çalışma geçmişi işletim sisteminin kullanıcıya özel uygulama verisi klasöründe saklanır. Yedek oluşturup taşımadığın sürece bu bilgisayarda kalır.

VERİLERİN

Varsayılan olarak yerel. AI kullanırken açıkça belirtir.

Hamartia çalışma kayıtlarını ve yüklenen görselleri bu bilgisayardaki kullanıcıya özel uygulama verisi klasöründe saklar. Hesap eşitlemesi yoktur. Çalışma ajanı için ChatGPT ile giriş henüz kullanılamıyor.

İsteğe bağlı soru analizi, soru metnini ve görselleri Ayarlar'da yapılandırdığın OpenAI uyumlu uç noktaya gönderebilir. Yalnızca güvendiğin bir uç noktaya bağlan. API anahtarı API yanıtlarına ve yedeklere eklenmez; uygulama anahtarı yerel ayar verisinde şifrelemeden saklar.

Yerel API yalnızca bu bilgisayarda kullanılmak üzere bağlanır. İnternete açık hale getirme.

YEDEKLEME VE GERİ YÜKLEME

Yanında götürebileceğin bir yedek.

ZIP yedeğini Ayarlar'daki Yedeği indir seçeneğiyle kaydet. Yedek çalışma kayıtlarını ve soru görsellerini içerir, yerel API anahtarını içermez.

Geri yüklemek için Ayarlar'dan Yedeği geri yükle seçeneğini aç, ZIP dosyasını seç ve işlemi onayla. Hamartia arşivi doğrular, mevcut veri klasörünün tarihli kopyasını saklar, bu bilgisayardaki API anahtarını korur ve ardından yeniden başlar.

Yedeği yalnızca Hamartia içinden geri yükle; sonuç mesajı görünene kadar uygulamayı açık tut.
