İşletim sistemine göre kurulum

Windows veya Linux için paketlenmiş masaüstü yükleyicisini seç.

Hamartia; Windows yükleyicisi, Debian paketi ve Linux AppImage yayımlar. Güncel dosyaları GitHub Releases sayfasından indir. Paketler x64 içindir; şu anda macOS paketi belgelenmiyor.

Windows 10/11

  1. Windows .exe yükleyicisini indir.
  2. Çalıştır ve yükleyici adımlarını izle. İstersen yükleme klasörünü seç.
  3. Kurulu kısayoldan Hamartia'yı aç. Kullanıcı verileri geçerli Windows kullanıcısının uygulama verisi dizininde ayrı tutulur.

Windows yükleyiciyi engeller veya uyarı verirse devam etmeye karar vermeden önce dosyanın projenin Releases sayfasından geldiğini doğrula. Başka yerlerdeki benzer adlı ikili dosyaları indirme.

Debian ve uyumlu dağıtımlar

Sürümdeki .deb dosyasını indir. Sistem paket yükleyicisinde aç veya dosyanın bulunduğu dizinde şu komutu çalıştır:

sudo apt install ./Hamartia-linux-x64.deb

Dosya adı farklıysa indirdiğin gerçek adı kullan. Paket yöneticisi bağımlılıkların kurulmasını isteyebilir.

Linux AppImage

AppImage'i indir ve bulunduğu dizinde şu komutları çalıştır:

chmod +x Hamartia-linux-x64.AppImage
./Hamartia-linux-x64.AppImage

Dosya adı farklıysa gerçek adı kullan. Bazı masaüstü ortamları FUSE veya sistem entegrasyonu gerektirir; açılmazsa dağıtımının belgelerine bak.

İlk açılış

Uygulama İngilizce açılır. Dili Ayarlar'dan değiştir. Yerel çalışma verileri işletim sistemi kullanıcısının uygulama veri klasöründe kalır ve kendin silmediğin sürece güncelleme veya yeniden kurulumdan sonra korunur. Kaldırmadan ya da bilgisayar değiştirmeden önce yedek al. Yedekleme ve geri yükleme ile Sorun giderme sayfalarına bak.
