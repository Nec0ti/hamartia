Troubleshooting

Recover from install, endpoint, restore, timer, and notification problems.

The installer or app will not open

Confirm you downloaded the matching package from the official Releases page and that the OS/architecture are supported. For AppImage, check the executable bit and your distribution's FUSE requirements. On Debian, install the downloaded .deb with apt or the system installer. If it still fails, record OS version and exact error text without private paths or tokens.

Study Agent or endpoint fails

Check the selected provider. For ChatGPT, confirm the desktop app is used, sign-in is connected, and the account can access the chosen model. For a configured endpoint, verify exact URL, model name, network/service availability, authentication, and the endpoint's format. Read any remote-host or HTTP warning. Hamartia does not silently fall back to another provider.

Backup will not restore

Keep the original ZIP and check that it is a Hamartia backup, complete, and not modified. Restore from Settings in the packaged desktop app. Do not manually unpack files into the live data folder. A failed validation should preserve existing data; keep the timestamped pre-restore snapshot and seek help before deleting data.

Timer or reminder appears late

Clock reconciles deadlines when the app runs and after it returns from suspension. Check the Clock tab for overdue items and verify device local date/time and time zone. OS notifications can be disabled or suppressed. The app cannot wake a sleeping device or notify after it closes.

Ask for help safely

Include app version, OS, language, steps, expected result, and exact non-sensitive error. Never share API keys, ChatGPT tokens, real question images, or unredacted backup files. See Privacy and Contributing.
